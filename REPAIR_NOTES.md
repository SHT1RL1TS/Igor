# Исправления и результаты проверки — 24.09.2026

## Найденные и исправленные проблемы

- В текущем `App.jsx` уже отсутствовала ссылка на неопределённую
  `handleSendMessage` со скриншота. Отправка выполняется обработчиком внутри
  `ChatWindow`. Проверены запуск приложения и отправка в браузере.
- Vite не проксировал API/WebSocket при прямом локальном запуске. Добавлены
  маршруты `/api`, `/socket.io` и `/avatars`; Socket.IO начинает с polling,
  затем переключается на WebSocket.
- Production Dockerfile копировал конфигурацию Nginx, проксирующую запросы
  обратно на сервер разработки. Теперь Docker Compose собирает статику,
  Nginx отдаёт её и проксирует backend; сервер запускается из скомпилированного JS.
  Добавлены проверки готовности и исключения `node_modules` из контекста сборки.
- Старый `frontend/package-lock.json` не проходил `npm ci`, а у backend lock-файла
  не было. Исправлены оба; Docker использует воспроизводимую установку `npm ci`.
- Старый Vite имел известные уязвимости. Установлен Vite 6.4.3 и совместимый
  React-плагин; аудит обеих частей завершился без известных уязвимостей.
- Рассылка сообщений зависела от отдельного события браузера и допускала
  рассылку несохранённых данных. Теперь сервер рассылает результат успешного
  INSERT. Клиент объединяет историю, HTTP-ответы и события по ID без дубликатов.
- После переподключения загружается пропущенная история. Ошибки загрузки и
  отправки видны пользователю, черновик сохраняется при неудачной отправке.
- Неверный тип `text` мог вызвать исключение до обработки ошибки. Добавлена
  проверка типов, положительных ID, длины текста, отсутствующих пользователей
  и чатов; ответы 400/404/413 не приводят к падению процесса.
- Профиль больше не предполагает `id = 1`: ID берётся из базы по имени.
- Исправлены адреса и стили шрифтов, выдача аватаров backend и отсутствовавшие
  файлы двух аватаров. Добавлен локальный запасной аватар без внешнего сервиса.
- Работает поиск по чатам. Исправлены выделение активного чата, доступность
  кнопок, поведение узкого экрана и завершение изменения ширины боковой панели.
- Неработающие кнопки выхода и изменения аватара заменены пояснением о демо.
  Полноценная авторизация не добавлялась; это по-прежнему демонстрационный проект.

## Что проверить на компьютере друга

Docker на этом компьютере не установлен: сборка и запуск Linux-контейнеров,
Nginx внутри контейнера и подключение к полноценному PostgreSQL 15 здесь
не выполнялись. Проверка браузерной production-сборки через Vite Preview
не заменяет эту проверку инфраструктуры.

Инструкции и команда `docker compose up -d --build --remove-orphans` находятся
в `README.md`. После запуска стоит открыть две вкладки, выбрать один чат,
отправить сообщение и перезагрузить страницу.

При передаче исходников не нужны каталоги `node_modules`, `.npm-cache`,
`frontend/build`, `backend/dist`, `frontend/test-results`: зависимости и сборки
создаются заново. Нужны lock-файлы, исходники, Dockerfile, конфигурации,
`postgres/init.sql`, файлы из `backend/public` и настройки `.env`.
